# Docs For AI Agents

This directory contains Markdown files intended for AI agents, coding assistants, and detailed project-maintenance notes.

- `CLAUDE.md` - instructions for Claude-style zip-in/zip-out workflows
- `BACKEND.md` - backend directory map
- `FRONTEND.md` - frontend directory map
- `SETUP.md` - detailed first-time deployment notes
- `SETUP_AUTH.md` - detailed OAuth setup notes
- `DEV_SETUP.md` - detailed dev/staging deployment notes
- `CHANGELOG.md` - project change history

Keep the main human-facing overview in the root `README.md`. Keep all other Markdown here.
